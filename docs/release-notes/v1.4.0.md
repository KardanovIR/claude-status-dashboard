## Install is one command now

```sh
curl -fsSL https://agstatus.online/install.sh | sh     # macOS, Linux
```
```powershell
irm https://agstatus.online/install.ps1 | iex          # Windows
```

Pairing from the mobile app passes straight through:
`curl -fsSL https://agstatus.online/install.sh | sh -s -- --code XXXX-XXXX`.

On macOS this also sets up **Focus**, so tapping a session on the board brings its
terminal to the front on the machine running it — and offers to resume it if the
session has already ended. `--no-focus` skips it.

## Two things to do after upgrading

**Codex users must re-run `/hooks`.** The Codex hook's command changed (its
configuration moved into a `0600` file beside the hook, so it works on Windows),
and that invalidates Codex's `trusted_hash`. Until you re-trust it, your Codex
sessions stop reporting.

**macOS listeners need one reinstall.** Existing installs keep working, but they
still name a Node path frozen at install time. Re-running the installer replaces it
with a launcher that finds Node at start-up, so a `brew upgrade node` or an
`nvm uninstall` no longer silently kills the listener. `agstatus listener doctor`
will tell you if yours predates it.

## npm, npx and Homebrew are retired as install channels

Retired, not withdrawn: `agstatus@1.3.0` stays on the npm registry forever, so an
`npx agstatus init` in an old script or a screenshot still works — it just installs
1.3.0. New versions ship only through the installers above, which download a
self-contained, checksum-verified artifact from this release.

## Also in this release

- Windows setup actually works. The hook registration was being written with a
  POSIX `$HOME` that cmd and PowerShell never expand, so it installed cleanly and
  then silently never fired.
- A slow reply no longer shows as a failure. All three boards used to treat their
  own 15-second deadline as the answer and discard the real one when it arrived,
  leaving a red card over a window that was already in front.
- The listener no longer reports `resumed` for a session it failed to start.
- Focus records are cheaper for Codex under fish and nu, where a cache that never
  hit was re-running full process-table detection between every tool call.
