Claude Code & Codex

A dashboard for many agent statuses at once.

Agents run for a long time and then quietly wait for you. AgStatus shows what each one is doing right now — and tells you the moment one needs your approval.

Source

Live board

Six states, one glance.

Every session reports as it works. The board is ordered by what changed last, so the thing that needs you rises to the top.

Blocked

Know when you're the bottleneck

An agent that hits a permission prompt turns red and sends a push notification, so a five-second approval doesn't cost you an hour.

Limits

Watch your plan, not the clock

Full-width bars for the current session window and weekly caps — per model, including Opus, Sonnet and Fable — with the time until each resets.

History

Replay what happened

Tap any session for its timeline: every status change and command, timestamped, so you can see where a long run actually went.

Yours

Open source, self-hostable

MIT licensed, one Node process and a Postgres database. Use the hosted board or run the whole thing on your own machine.

It lives in your pocket.

The iPhone app shows the same board, and keeps a timeline of everything each agent did. Try it without pairing anything — the app ships with a demo board.

Running in about a minute.

One command wires up the hooks. No account, no sign-up — a board is just an unguessable URL.

01

Install the hook

Sets up Claude Code, and OpenAI Codex too when it finds it. Your existing settings are preserved.

npx agstatus init brew install kardanovir/tap/agstatus && agstatus init /plugin marketplace add KardanovIR/claude-status-dashboard
/plugin install agstatus@agstatus
/agstatus:setup

Runs inside Claude Code — no terminal needed. Claude Code only; for Codex use the CLI.

02

Open the board

The CLI prints your private board URL and a QR code — scan it to carry the board on your phone.

03

Get back to work

Sessions appear the moment your agents report in, and update live. Nothing else to configure.

What it sends

A session id, project folder name, status word, and a short activity line. Run init --minimal to send tool names only.

Plan usage stays local

Your Claude credentials are read on your machine. Only percentages and reset times reach the board — never a token.

Your data, deletable

Sessions expire after 24 hours; a board can be deleted at any time. Privacy policy.
