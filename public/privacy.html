AgStatus

Privacy Policy

Last updated: August 2, 2026

AgStatus is an open-source status board for coding agents such as Claude Code and OpenAI Codex. This policy covers the AgStatus iOS app and the hosted server at agstatus.online, operated by the project maintainer.

The short version. There are no accounts and no tracking. The server stores only the small status updates your own machine sends it, deletes them automatically after 24 hours, and you can delete everything at any time.

What the server stores

When you set up the hooks (npx agstatus init), your machine sends the server a small update each time an agent changes what it is doing:

FieldExampleNotes
Session id9f3c…Generated by your coding tool
Projectmy-repoThe folder name of the project
StatuscodingOne of six fixed words
Messagenpm testA short activity line, truncated
Timestamps—When each change happened, for the session timeline

By default the message can include a truncated command line (up to 120 characters) so the board is useful at a glance. If you would rather not send command text, run npx agstatus init --minimal — messages then contain only tool names, such as "Bash".

A board is identified only by an unguessable random token in its URL. Anyone who has that URL can view the board, so treat it like a password.

Plan usage

The hook can also report how much of your plan's rate limits you have used, so the board can show limit bars. The credentials used to look this up are read on your own machine and never sent to the server — only the resulting percentages and reset times are. Set AGSTATUS_USAGE=off to turn this off entirely.

What we do not collect

  • No accounts, email addresses, or passwords.
  • No analytics, advertising identifiers, or third-party SDKs.
  • No source code, file contents, or agent conversations.
  • No credentials or API keys of any kind.

Push notifications

If you turn on notifications in the iOS app, they are delivered through Apple's push service (APNs). A notification contains only the session name and its short status message — the same text your hook already sent to your board. Your device's push token is stored with your board and is removed when you turn notifications off, when the token expires, or when the board is deleted.

What the app stores on your device

The iOS app keeps your board's URL and token in the iOS Keychain on your device. It makes network requests only to the board server you configure. Demo mode runs entirely on-device and sends nothing anywhere. The app requests camera access only when you choose to scan a setup QR code, and the camera is used for nothing else.

Retention and deletion

  • Sessions are deleted automatically 24 hours after their last update.
  • Boards untouched for 60 days are deleted with all their data.
  • You can delete a board and everything in it at any time, from the app (Settings → "Delete board") or with one request: curl -X DELETE https://agstatus.online/w/<token>

Deleted data is removed from the service immediately: it stops being served, shown, or returned by the API. Records are first flagged as deleted rather than erased on the spot, and are cleared from the database during routine maintenance.

Self-hosting

AgStatus is open source under the MIT license. You can run the entire server yourself, in which case no data reaches the hosted instance at all. See the self-hosting guide.

Children

AgStatus is a developer tool and is not directed at children under 13.
